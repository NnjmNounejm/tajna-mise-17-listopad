# Tajná mise: 17. listopad

Jednoduchá webová hra pro žáky 4. třídy o událostech 17. listopadu 1989 a Sametové revoluci.

## Jak spustit hru pro žáky (iPad)

1. Jdi do **Settings** tohoto repozitáře
2. V levém menu klikni na **Pages**
3. U Source vyber **Deploy from a branch**
4. Branch: `main` + složka `/ (root)`
5. Klikni **Save**

Po 1–2 minutách bude hra dostupná na adrese:

**https://nnjmnounejm.github.io/tajna-mise-17-listopad/**

Tento odkaz můžeš poslat žákům – na iPadu se otevře přímo v Safari.
